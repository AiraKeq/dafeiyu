# 大肥鱼 v1.6.0：联网核验、命令静默、25秒冷却

本轮只改用户要求的三处，保留向量记忆、成长、权限、回复时段、分页和识图；生产暂停交付，不自动启用。

- 普通聊天默认/正式配置冷却25秒，从完整回复结束起算；@与原“大肥鱼/鲸鲸/鲸鱼娘/大鲸鱼/小鲸鱼”仍绕过冷却立即开始处理。实际检索与生成仍需时间。
- `/help`、未知slash命令、称呼/@后的命令及QQ“鲸鱼记忆/风格”控制入口静默拦截，不记忆/排队/进模型/发送。框架Waking阶段参数错误可能先send，已用有所有权的作用域前置guard拦住，热重载只撤本插件的wrapper。句中引用/help、URL或普通讨论不误挡；管理请用本机管理器。
- 用现有文字/视觉模型判定需要核验的公开词或表情画面，至多2个隐私过滤短查询。未知、明确求含义/出处的公开梗优先搜索。私人聊天不发公网；QQ原图不上传新增搜索站。
- DDGS 9.9.3 + primp 0.15.0 放独立依赖目录/一次性worker，指定实测可用Yahoo/Yandex/Wikipedia；无新增Key、代理或搜索服务器。首轮遇primp2.0不兼容已固定版本，避免运行时自动升级。
- 搜索只取带公共URL的摘要，明确未核验全文/原图出处，不执行网页指令。无来源、失败、识别不清、隐私阻断时，在模型response与发送前装饰两层强制替换短句，不能只靠提示让它自行猜。
- 所有回复仍走原最多三条单页与完整分页链；检索不会向QQ发送“搜索中”或工具列表。

验证包括原功能+新增纯政策345项回归、53项管理器回归、75项真实AstrBot断网native命令/冷却/回退与既有场景；既有官方模型用纯合成文字/图片验证路由，普通私事情绪聊天skip，公开词与图片search；真实搜索公开“鸡你太美”返回带URL资料。测试不发送QQ消息、不修改正式聊天事实。
