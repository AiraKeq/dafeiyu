# astrbot_plugin_neural_network_memory

**llm神经网络记忆**

- 作者：浅月tniay
- 版本：v1.0.0
- 支持 AstrBot 版本：>=4.16,<5
- 支持平台：aiocqhttp、telegram

## 简介

这是一个模仿人类神经网络记忆运作方式的 AstrBot 插件。插件将大语言模型（LLM）的"记忆"机制进行结构化建模，区分短期记忆与长期记忆，并引入记忆衰退、记忆增强、自主学习、好感度转变与人格扮演增强等机制，让 AI 的对话表现更接近真实人类的记忆与情感反应。

通过本插件，LLM 不再仅依赖上下文窗口的临时文本，而是能够"记住"用户的关键信息、随时间弱化旧记忆、在合适时机巩固重要记忆，并根据与用户的关系亲密度调整回复语气，从而实现更自然、更连贯、更具人格一致性的长期交互。

## 核心功能

### 双层记忆模型

模仿人类大脑的工作记忆与持久记忆，将记忆划分为两层：

- **短期记忆（工作记忆）**：最近接收到的信息，生命周期短、衰减快，用于支撑当前对话上下文。
- **长期记忆（持久记忆）**：经过巩固后保存下来的重要信息，生命周期长、衰减慢，用于跨会话的持久回忆。

两层记忆具有不同的初始强度、衰减率与容量上限，形成类似人类"瞬时记忆→短时记忆→长时记忆"的层级流转。

### 记忆衰退

记忆强度会随时间自动衰减，模仿人类"遗忘"机制：

- 短期记忆每次衰减比例较大，遗忘速度快。
- 长期记忆每次衰减比例较小，遗忘速度慢。
- 当某条记忆的强度低于遗忘阈值时，将被自动遗忘或降级处理。

衰减检查按固定时间间隔触发，无需用户操作。

### 记忆增强

记忆被使用时会变得"更牢"，模仿人类"越用越牢"的神经可塑性：

- **召回增强**：记忆被召回参与 LLM 请求时，强度按 `recall_boost` 系数提升。
- **弱增强**：用户发言命中某条记忆的标签时，该记忆强度按 `weak_boost` 系数小幅提升，即使该记忆未被正式召回也能被"激活"。

### 短期→长期巩固

模仿人类睡眠期的记忆巩固过程：

- 当一条短期记忆被召回次数达到 `consolidation_recall_threshold` 时，自动升级为长期记忆。
- 当一条短期记忆的强度达到 `consolidation_strength_threshold` 时，也会自动升级为长期记忆。

巩固后的记忆将获得更高的初始强度与更慢的衰减率，从而更持久地保留。

### 记忆回顾

在每次 LLM 请求前，插件会根据当前用户发言召回相关记忆，并将其注入 system_prompt，实现"人性化回忆"：

- 召回数量受 `recall_top_n` 限制，避免 token 过度膨胀。
- 召回过程综合考虑记忆的相关度与强度，优先返回最相关、最牢固的记忆。
- 被召回的记忆同时触发召回增强。

### 短期记忆模式

提供"短期记忆模式"开关，开启后仅使用短期记忆参与上下文：

- 减少 token 负担，适用于低配额场景或快速对话。
- 长期记忆仍会被维护与衰减，但不参与召回注入。
- 可通过 `nn_mode` 指令在完整模式与短期模式之间切换。

### 自主学习

每轮对话结束后，插件会自动分析用户发言，抽取可记忆信息：

- 无需 LLM 主动调用工具即可完成记忆抽取。
- 自动为新记忆生成标签与重要性评分。
- 抽取后的记忆会进入短期记忆池，并触发对相关旧记忆的弱增强。

自主学习可通过 `auto_learn_enabled` 配置项关闭。

### 好感度系统

按用户交互模式自动升降好感度（0-100），并将关系划分为四个阶段：

- **陌生**：初始阶段，AI 回复语气较为中性、礼貌。
- **熟悉**：好感度积累后，语气更为自然、贴近日常交流。
- **亲近**：好感度较高，语气更具亲和力与关怀感。
- **挚友**：最高阶段，语气最为亲密、信任。

好感度变化由正向交互增量与负向交互减量控制，影响 AI 回复语气的亲密度，但不会覆盖原有人格设定。

### 人格扮演增强

综合好感度阶段、用户偏好与长期记忆，动态生成人格扮演提示并注入 system_prompt：

- 加强角色一致性与扮演深度。
- 不覆盖原有人格，仅作增强性补充。
- 可通过 `persona_enhance_enabled` 配置项关闭。

### LLM 主动记忆工具

插件向 LLM 注册 `record_memory` 函数工具，LLM 可在对话过程中主动判断哪些信息值得记住并调用该工具进行记录，与自主学习机制形成互补。

## 工作原理

插件围绕一次完整的对话循环运作，分为"请求前"与"回复后"两个阶段：

**请求前阶段（LLM 请求前）**

1. 接收用户发言。
2. 根据用户发言召回相关记忆（短期与/或长期，取决于当前模式）。
3. 读取当前用户的好感度与关系阶段，生成好感度阶段提示。
4. 综合好感度阶段、用户偏好与长期记忆，生成人格扮演增强提示。
5. 将召回的记忆、好感度提示与人格增强提示一并注入 system_prompt。
6. 将增强后的请求发送给 LLM。

**回复后阶段（LLM 回复后）**

1. 自主学习引擎分析用户发言，抽取可记忆信息并生成标签与重要性评分。
2. 对被命中的旧记忆执行弱增强。
3. 检查短期记忆是否满足巩固条件，满足则自动升级为长期记忆。
4. 根据本轮交互模式更新用户好感度。
5. 按衰减检查间隔触发记忆衰退，遗忘强度过低的记忆。

上述两个阶段构成一个完整的"感知—回忆—回复—学习—巩固—遗忘"循环，使 AI 的记忆与情感状态随交互持续演化。

## 配置说明

所有配置项定义于 `_conf_schema.json`，可在 AstrBot 管理面板中修改。

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| enabled | bool | true | 插件总开关，关闭后所有功能均不生效 |
| decay_enabled | bool | true | 是否启用记忆衰退，关闭后记忆强度不再随时间衰减 |
| short_decay_rate | float | 0.15 | 短期记忆每次衰减比例，取值范围 0-1，越大遗忘越快 |
| long_decay_rate | float | 0.03 | 长期记忆每次衰减比例，取值范围 0-1，应低于短期衰减率 |
| forget_threshold | float | 0.1 | 记忆强度低于此值则遗忘，取值范围 0-1 |
| decay_check_interval | int | 3600 | 衰减检查间隔，单位秒，每隔该时间执行一次衰减 |
| recall_top_n | int | 5 | 每次召回的记忆数量上限 |
| consolidation_recall_threshold | int | 3 | 短期记忆被召回多少次后巩固为长期记忆 |
| consolidation_strength_threshold | float | 0.8 | 短期记忆强度达到此值时巩固为长期记忆，取值范围 0-1 |
| short_term_initial_strength | float | 0.5 | 短期记忆创建时的初始强度 |
| long_term_initial_strength | float | 0.7 | 长期记忆创建时的初始强度，应高于短期初始强度 |
| recall_boost | float | 0.15 | 记忆被召回时的强度增强系数 |
| weak_boost | float | 0.05 | 弱增强系数，用户发言命中标签时记忆强度的小幅提升值 |
| max_short_term | int | 100 | 短期记忆最大数量，超出后移除强度最低的 |
| max_long_term | int | 200 | 长期记忆最大数量，超出后移除强度最低的 |
| auto_learn_enabled | bool | true | 是否启用自主学习，开启后自动抽取记忆 |
| affinity_enabled | bool | true | 是否启用好感度系统，关闭后不计算好感度变化 |
| affinity_default | int | 50 | 新用户初始好感度，取值范围 0-100 |
| affinity_positive_gain | int | 2 | 正向交互好感度增量 |
| affinity_negative_loss | int | 3 | 负向交互好感度减量 |
| persona_enhance_enabled | bool | true | 是否启用人格扮演增强，关闭后不注入人格增强提示 |

## 安装与使用

### 安装

1. 将整个 `astrbot_plugin_neural_network_memory` 目录放入 AstrBot 的插件目录（通常为 `data/plugins/`）。
2. 本插件仅依赖 Python 标准库，无需额外安装第三方依赖。
3. 重启 AstrBot 或在管理面板中重新加载插件，插件即可自动加载。
4. 在 AstrBot 管理面板的插件配置页中，根据需要调整各项参数。

### 使用

- 安装完成后，插件默认开启全部功能（记忆衰退、自主学习、好感度系统、人格扮演增强）。
- 直接与机器人对话即可，插件会在每次对话前后自动执行记忆维护流程，无需手动操作。
- 如需查看或手动管理记忆，可使用上文"指令列表"中的指令。
- 如需降低 token 消耗，可使用 `nn_mode` 切换至短期记忆模式，或在配置中关闭人格扮演增强。
- 用户记忆数据以 JSON 文件形式持久化保存于 `data/neural_memory/users/` 目录下，按用户隔离。
